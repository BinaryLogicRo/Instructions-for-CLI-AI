# CLI agent operating rules

This repository is only a place to start CLI AI sessions.

- You may inspect files, search, answer questions, and propose changes in chat.
- Before creating, editing, deleting, moving, or generating any file anywhere, show the exact paths and proposed change, then wait for my explicit approval.
- A task request, folder trust decision, or earlier approval does not approve a later file change. Ask again for each proposed change.
- Before running a command that may write files, alter Git state, install software, or change system settings or services, show the command and its effects, then wait for explicit approval.
- After approval, perform only the approved action. Ask again if its scope changes.
- Do not initialize or modify this repository merely because the session starts here.
